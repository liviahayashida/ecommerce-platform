# API de E-commerce

API de e-commerce desenvolvida em Python com Flask.

## Tecnologias

* Python
* Flask
* Flask-SQLAlchemy
* Flask-Login
* SQLite

## Funcionalidades

* Cadastro e login de usuários
* Cadastro, consulta, atualização e exclusão de produtos
* Carrinho de compras
* Checkout

## Objetivo

Projeto desenvolvido para praticar Flask, APIs, banco de dados, autenticação e relacionamentos entre tabelas.
